Test Cases: TC_RENTAL_01 (Gửi thành công khi phòng trống), TC_RENTAL_02 (Chặn đặt phòng đang thuê hoặc bảo trì).

Use Case: UC05 - Lập hợp đồng mới (Manage Contract)
Tác nhân: Chủ trọ (Landlord) → ManageContractsScreen → ContractController → Room & Contract Collection
Test Cases: TC_CTR_01 (Lập hợp đồng thành công, phòng tự chuyển RENTED), TC_CTR_02 (Chặn lập trùng hợp đồng).
sequenceDiagram autonumber actor Landlord as Chủ trọ (Landlord) participant UI as Frontend (ManageContractsScreen) participant API as ContractController participant RoomDB as MongoDB (Room) participant CtrDB as MongoDB (Contract) Landlord->>UI: 1. Nhập thông tin Bên A, Bên B, ngày ký, thời hạn, cọc, giá thuê Landlord->>UI: 2. Bấm "Xác nhận lập hợp đồng" activate UI UI->>API: 3. POST /api/contracts (roomId, Bên A, Bên B, signedDate, startDate, endDate, cọc, giá) activate API API->>RoomDB: 4. Room.findById(roomId) activate RoomDB RoomDB-->>API: 5. Thông tin phòng deactivate RoomDB API->>CtrDB: 6. Contract.findOne({ roomId, status: 'ACTIVE' }) activate CtrDB CtrDB-->>API: 7. Kết quả tìm kiếm hợp đồng đang ACTIVE deactivate CtrDB alt [TC_CTR_02] Phòng đang RENTED hoặc đã có hợp đồng ACTIVE API-->>UI: 8a. 400 Bad Request ("Phòng đang có hợp đồng hoặc đã thuê") UI-->>Landlord: 9a. Cảnh báo lỗi lập trùng hợp đồng else [TC_CTR_01] Dữ liệu hợp lệ & Phòng còn trống (AVAILABLE) API->>CtrDB: 8b. Contract.create(status: 'ACTIVE', signedDate, Bên A, Bên B, ...) activate CtrDB CtrDB-->>API: 9b. Hợp đồng lưu thành công deactivate CtrDB API->>RoomDB: 10b. Cập nhật phòng thành công deactivate RoomDB API-->>UI: 12b. 201 Created (Tạo hợp đồng thành công) deactivate API UI-->>Landlord: 13b. Thông báo thành công, mở nút "👁️ Xem HĐ" để xem và in end deactivate UI

Tác nhân: Chủ trọ (Landlord) → ManageContractsScreen → ContractController → Contract Collection
sequenceDiagram autonumber actor Landlord as Chủ trọ (Landlord) participant UI as Frontend (ManageContractsScreen) participant API as ContractController participant CtrDB as MongoDB (Contract) Landlord->>UI: 1. Bấm nút "Gia hạn" tại hàng hợp đồng Landlord->>UI: 2. Nhập ngày kết thúc mới (newEndDate) activate UI UI->>API: 3. PUT /api/contracts/:id/extend ({ endDate: newEndDate }) activate API API->>CtrDB: 4. Contract.findById(id) activate CtrDB CtrDB-->>API: 5. Báo lỗi trạng thái không hợp lệ else Hợp đồng ACTIVE hợp lệ API->>CtrDB: 6b. Cập nhật contract.endDate = newEndDate & save() activate CtrDB CtrDB-->>API: 7b.
